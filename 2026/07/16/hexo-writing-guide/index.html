1. 新建一篇博客

3. 文章中插入图片（无需图床）

本项目已开启 post_asset_folder: true，每篇文章都有一个同名资源文件夹。把图片放入该文件夹后，图片会随文章一起生成、一起部署到 GitHub，不需要任何外部图床。

五、常用命令速查表

命令 简写 说明
hexo new "标题" - 新建文章
hexo new page "x" - 新建页面（如关于页）
hexo server hexo s 启动本地预览（端口 4000）
hexo generate hexo g 生成静态文件
hexo deploy hexo d 部署到远程仓库
hexo clean - 清理缓存与 public 目录
hexo list post - 列出所有文章
