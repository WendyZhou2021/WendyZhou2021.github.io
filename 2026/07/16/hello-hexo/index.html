你好，Hexo！

这是一篇示例文章，恭喜你的博客已经成功搭建完成！🎉

本博客基于 Hexo 构建，并部署在 GitHub Pages 上。

功能特性

  • 📝 使用 Markdown 编写文章
  • 🎨 丰富的主题与插件生态
  • 🚀 一键部署到 GitHub Pages
  • 🔍 支持分类、标签、归档

代码示例

下一步

  1. 修改 _config.yml 自定义站点信息
  2. 运行 hexo new "文章标题" 创建新文章
  3. 运行 hexo clean && hexo generate && hexo deploy 发布

更多文档请参考：Hexo 官方文档
